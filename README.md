# Black Friday — Dra. Gerlany Melo 💎

Página ponte (*bridge page / pre-lander*) mobile-first minimalista, refinada e de alta conversão para direcionamento de tráfego pago para o Grupo VIP do WhatsApp da Dra. Gerlany Melo.

## 🚀 Tecnologias e Recursos
- **Visual Black & Marsala / Red Glow**: paleta refinada em preto com auréola vermelha pulsante e ambientação monocromática de luxo.
- **Identidade da Campanha**: logo oficial da Black Friday e faixa decorativa contínua.
- **Tipografia Delicada**: `Cormorant Garamond` (serif refinada) e `Montserrat` (pesos finos 200/300/400).
- **CTA Otimizado WhatsApp**: botão contrastante com link oficial para o Grupo VIP.
- **Prova Social Dinâmica (FOMO)**: notificações flutuantes refinadas de entrada de novas pacientes em tempo real.
- **Servidor Local Node.js**: servidor estático leve sem dependências externas.

## 📱 Visualização Local
```bash
node server.js
```
Acesse em: `http://localhost:3000`
